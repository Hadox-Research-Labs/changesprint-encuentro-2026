# Caso E3-02 — Información incompleta

## Propuesta GOV-202

Usar una herramienta generativa para revisar solicitudes y acelerar el proceso. La propuesta afirma que reducirá tiempos, pero no identifica qué documentos utilizará, quién revisará la salida, cuánto tiempo conservará datos, cómo se explicarán errores ni qué condición detendría el sistema.
