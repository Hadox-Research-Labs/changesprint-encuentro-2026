# Equipo 3 — Auditor de gobernanza de IA

## Misión

Configurar una skill que revise una propuesta ficticia de uso de inteligencia artificial antes de un piloto y señale controles faltantes.

## Entregable de la skill

La skill debe revisar:

1. Finalidad y alcance.
2. Datos autorizados y minimización.
3. Herramientas y permisos.
4. Responsable humano.
5. Evidencia, registros y explicación.
6. Corrección o apelación.
7. Condiciones para continuar, corregir o detener.

Utiliza `$skill-creator` y guarda la skill dentro de `skills/auditor-gobernanza/`.
