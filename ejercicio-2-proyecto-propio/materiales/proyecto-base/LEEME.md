# Proyecto base

1. Copien esta carpeta y pónganle el nombre del prototipo.
2. Completen `AGENTS.md` a partir del contrato del agente.
3. Coloquen únicamente fuentes autorizadas en `fuentes/`.
4. Diseñen casos ficticios en `casos/`.
5. Creen la skill dentro de `skills/` después de aprobar el contrato.
6. Definan `formato-salida.md`.
7. Guarden las ejecuciones en `resultados/`.
8. Registren pruebas y correcciones en la bitácora del cuaderno.
